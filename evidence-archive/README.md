# Evidence Preservation Archive

This directory retains version and document metadata produced from registered public-record sources.

- Only material already available from public sources may be stored here.
- Source and document records carry retrieval dates, SHA-256 hashes and evidence boundaries.
- Credentials, private submissions, member data, unpublished allegations and administrator controls must never be stored here.
- Cloudflare packaging explicitly excludes this directory and the internal snapshot diagnostics from public site assets.

A changed, removed, unavailable or restored source is a preservation observation. It is not proof of concealment, document destruction, misconduct, intent or criminal wrongdoing.
