Automation Loop

01

Generate

Open the queue and generate the next batch using the prepared prompts.

02

Drop Into Inbox

Add each finished image as a pending item with deckId, cardId, label and sourceUrl or sourceDataUri.

03

Install

The installer writes the image asset, replaces the expected SVG card wrapper, and updates the install log.

04

Rebuild

The normal build checks downloads, dossiers, artwork routes, public copy and intake health.

Inbox Item Format

{
  "deckId": "people-of-interest",
  "cardId": "george-soros",
  "label": "George Soros",
  "sourceUrl": "https://example.com/card.webp",
  "status": "pending"
}

Use sourceDataUri instead of sourceUrl when the image is embedded as a data URL.

Boundary

Artwork is presentation only. Evidence, current intelligence, scores, source routes and corrections stay in the card dossier and source ledger.

Artwork pipeline: queue → inbox → installer → manifest → dossier.
